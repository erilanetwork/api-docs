# Limits

| What                               | Limit          |
| ---------------------------------- | -------------- |
| Commands returned per poll         | 50             |
| Results processed per ack request  | 200, the rest are ignored |
| Lease length                       | 60 seconds     |
| Online player names kept per poll  | 500            |
| `error` length in an ack           | 500 characters |
| Recommended poll interval          | 5 to 10 seconds |
